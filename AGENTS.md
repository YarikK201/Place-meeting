# Instructions for AI-assisted development

Project: "Место встречи" / Place-meeting; existing MAX bot: https://max.ru/ideya_fiks_103_bot.

## Boundaries
- Do not request, display, generate, commit, or log real tokens, student identities, or personal data.
- Never disable TLS/certificate verification. MAX API is https://platform-api2.max.ru.
- Do not make live MAX API requests, modify bot settings, send messages, or create webhook subscriptions without human approval.
- Use environment variable MAX_BOT_TOKEN; keep secrets outside repository and AI task prompts.
- Implement changes in reviewable, small pull requests. Include tests and update documentation.
- Production should use webhook; polling is a local development fallback only.
- The team must understand, review, and author substantial elements of the hackathon submission. Official rules §9.5 prohibit materials wholly or predominantly generated by generative AI; get organizer clarification before using generated code in submission.
- Privacy-by-design: project concerns minors. No public directory exposing identifying details, no unsolicited contact, moderation and consent requirements before matching launches.

## Scope
Prototype starts with a read-only /me check and an opt-in, private-dialog /start response.
Later modules: event catalog, search filters, saved opportunities, team matching, teacher workflows.
The repository documentation, team user flow, and backend scheme remain product requirements to be reviewed by the team.
