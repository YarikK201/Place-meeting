ОБНОВЛЕНИЕ ФИЛЬТРАЦИИ «МЕСТО ВСТРЕЧИ»

Содержимое: filters.py и пример интегрированного bot.py.
Источник требований: приложенный документ «Тексты интерфейса и схема переходов».

ВАЖНО: Если вы после последнего обмена изменяли bot.py локально, сделайте резервную копию
и сравните перед заменой. В архиве версия bot.py с каталогом, избранным,
регистрацией и кнопкой «Моя анкета».

1. Скопируйте filters.py и bot.py в папку Place-meeting.
2. Убедитесь, что есть catalog.py, favorites.py, profiles.py.
3. В Dockerfile должен быть COPY, включающий filters.py, bot.py и остальные файлы.
4. Проверьте синтаксис: python -m py_compile bot.py filters.py
5. Пересоберите Docker и пересоздайте контейнер, не удаляя volume.

Фильтры: тематика (мультивыбор), возраст (мультивыбор), место (города с
известными соответствиями), дата (включая календарный выбор), формат.
Значения сохраняются на пользователя в таблице event_filters.

ОГРАНИЧЕНИЯ:
- В текущем JSON status=null для всех мероприятий. Модерация в этой версии
  не реализована: записи тестового каталога показываются как есть.
- Город для неизвестных площадок не выдумывается. Для расширения обновите
  словарь CITIES и известные площадки в filters.py.
- Дата поддерживает YYYY-MM-DD HH:MM:SS, ISO-диапазоны, «бессрочно» и
  «с ДД.ММ.ГГГГ». Другие диапазоны требуют нормализации исходных данных.
- Изменение JSON требует перезапуска бота / повторного импорта.
- Главное меню как отдельный экран этим обновлением не добавляется.

ВНИМАНИЕ: кнопки MAX не тестировались с реальным подключением к MAX API;
тестирование синтаксиса и SQLite выполнено локально с имитацией кнопок.
